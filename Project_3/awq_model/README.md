This is [LFM2.5-1.2B-Instruct](https://huggingface.co/LiquidAI/LFM2.5-1.2B-Instruct) quantized with [llm-compressor](https://github.com/vllm-project/llm-compressor) using AWQ (asymmetric 4-bit activation-aware quantization). The model is compatible with vLLM (tested: v0.13.0). Tested with an RTX 4090.
